# LispKit Interpreter

## О проекте

**LispKit Interpreter** --- консольное Java-приложение для разбора и
интерпретации выражений языка LispKit.

Программа преобразует введённое выражение в абстрактное синтаксическое
дерево (AST), представленное ячейками `ATOM` и `CONS`, а затем выполняет
его с использованием окружения интерпретации. Вычисленное значение
преобразуется обратно в AST и выводится в консоль.

Проект демонстрирует синтаксический разбор, представление списков,
вычисление выражений, работу с переменными, функциями и рекурсией.

## Возможности

-   Чтение LispKit-выражений из консоли.
-   Разбор атомов и вложенных списков.
-   Построение AST на основе ячеек `ATOM` и `CONS`.
-   Представление списков через поля `HEAD` и `TAIL`.
-   Вычисление арифметических операций `ADD`, `SUB`, `MUL`, `DIV`,
    `REM`.
-   Сравнение с помощью `EQUAL` и `LE`.
-   Работа со списками: `QUOTE`, `CONS`, `CAR`, `CDR`, `ATOM`.
-   Условные выражения `COND`.
-   Создание и вызов функций с помощью `LAMBDA`.
-   Локальные определения через `LET`.
-   Рекурсивные определения функций через `LETREC`.
-   Вывод AST, CONS-дерева и результата вычисления.
-   Преобразование вычисленного значения обратно в AST.
-   Обработка ошибок разбора и вычисления.

## Основные классы

### `Ast`

Выполняет синтаксический разбор, строит AST из ячеек `ATOM` и `CONS`,
проверяет структуру выражений, восстанавливает исходную запись и
предоставляет методы вывода дерева и содержимого памяти.

### `Cell`

Представляет ячейку памяти AST. `ATOM` хранит атомарный элемент --- имя
операции, символ или число. `CONS` хранит ссылки `HEAD` и `TAIL`: первая
указывает на первый элемент, вторая --- на оставшуюся часть списка.

### `LispValue`

Представляет значения во время вычисления: числа, символы, списки,
функции и пустой список.

### `Environment`

Хранит соответствия между именами переменных и значениями. Поддерживает
вложенные окружения через ссылку на родительское окружение.

### `Evaluator`

Выполняет вычисление AST: обрабатывает операции, переменные, условные
конструкции и вызовы функций. Также преобразует вычисленное значение
обратно в AST.

### `LispKitConsole`

Организует консольное взаимодействие: считывает выражение, запускает
разбор и вычисление, выводит дерево и результат.

### `Main`

Точка входа приложения, запускающая консольный интерфейс.

## Представление выражений

В основе AST лежат два вида ячеек:

  Тип      Назначение
  -------- -----------------------------
  `ATOM`   Атомарный элемент выражения
  `CONS`   Пара ссылок `HEAD` и `TAIL`

Например, выражение `(SUB 3 7)` представляется списком из трёх
элементов: `SUB`, `3` и `7`. Список формируется цепочкой CONS-ячеек и
завершается значением `NIL`.

``` text
CONS
├── HEAD → ATOM(SUB)
└── TAIL → CONS
    ├── HEAD → ATOM(3)
    └── TAIL → CONS
        ├── HEAD → ATOM(7)
        └── TAIL → NIL
```

Вложенные выражения также представляются списками. Например, в
`(SUB (ADD 2 4) 7)` внутренний список `(ADD 2 4)` включается в AST
внешнего выражения.

## Поддерживаемые конструкции

  Конструкция                         Назначение
  ----------------------------------- -------------------------------------------------
  `ADD`, `SUB`, `MUL`, `DIV`, `REM`   Арифметические операции
  `EQUAL`, `LE`                       Сравнение значений
  `QUOTE`                             Возвращает выражение без вычисления
  `CONS`                              Создаёт пару из значения и списка
  `CAR`, `CDR`                        Получение головы и хвоста списка
  `ATOM`                              Проверка, является ли значение атомом
  `COND`                              Условное вычисление
  `LAMBDA`                            Создание функции
  Вызов функции                       Вычисление аргументов и выполнение тела функции
  `LET`                               Создание локальных определений
  `LETREC`                            Создание рекурсивных определений функций

## Принцип работы

1.  Пользователь вводит выражение LispKit.
2.  `Ast` разбирает строку и строит AST из ячеек `ATOM` и `CONS`.
3.  Исходная структура выводится в консоль.
4.  Создаётся окружение интерпретации.
5.  `Evaluator` получает корневой адрес AST и выполняет выражение.
6.  Во время вычисления обрабатываются операции, переменные, условные
    конструкции и вызовы функций.
7.  Полученное значение преобразуется обратно в AST.
8.  В консоль выводятся результат вычисления и его CONS-представление.

## Примеры вычисления

### Арифметическое выражение

Ввод:

``` lisp
(ADD 9 4)
```

Результат: `13`.

### Локальные определения `LET`

Ввод:

``` lisp
(LET (SUM X Y) (SUM (LAMBDA (A B) (ADD A B))) (X (QUOTE 8)) (Y (QUOTE 4)))
```

Результат: `12`.

В примере создаётся функция `SUM`, принимающая два аргумента. В
локальном окружении задаются значения `X` и `Y`, после чего вызывается
функция сложения.

### Условное выражение `COND`

Для примера используется окружение, в котором задано соответствие
`X → (G)`.

Ввод:

``` lisp
(COND (ATOM (QUOTE X)) (CONS X (QUOTE (A D))) (CAR (CDR Y)))
```

Результат:

``` lisp
((G) A D)
```

Условие истинно, поэтому вычисляется вторая ветвь `COND`. Третья ветвь
не вычисляется.

### Рекурсивная функция факториала

Ввод:

``` lisp
(LETREC (FACT (QUOTE 5)) (FACT (LAMBDA (N) (COND (EQUAL N 0) (QUOTE 1) (MUL N (FACT (SUB N 1)))))))
```

Результат: `120`.

### Рекурсивная функция длины списка

Ввод:

``` lisp
(LETREC (LENGTH (QUOTE (A B C))) (LENGTH (LAMBDA (L) (COND (ATOM L) (QUOTE 0) (ADD (QUOTE 1) (LENGTH (CDR L)))))))
```

Результат: `3`.

Функция последовательно обрабатывает хвост списка с помощью `CDR` и
увеличивает результат на единицу. Для пустого списка возвращается `0`.

## Обработка ошибок

Программа обрабатывает ошибки, возникающие при разборе и вычислении
выражений. В частности, предусмотрены сообщения для следующих ситуаций:

-   некорректная структура скобок;
-   нарушение допустимого синтаксиса выражения;
-   обращение к неопределённой переменной;
-   передача значения неподходящего типа операции;
-   деление на ноль;
-   попытка выполнить операцию над неподходящей структурой данных.

При возникновении перехватываемой ошибки программа выводит сообщение и
продолжает работу консоли.

## Запуск

Для запуска требуется JDK 17 или совместимая версия Java.

В IntelliJ IDEA:

1.  Откройте проект `LispKitInterpreter`.
2.  Убедитесь, что выбран JDK 17.
3.  Найдите класс `Main`.
4.  Запустите метод `main`.
5.  Введите выражение LispKit в консоли.

Для завершения работы введите `0`.

## Назначение проекта

LispKit Interpreter демонстрирует путь от текстовой записи
Lisp-подобного выражения до его вычисления. Проект объединяет
синтаксический разбор, построение AST, представление списков через
CONS-ячейки, работу с окружениями и интерпретацию выражений.

Реализация позволяет изучить рекурсивную обработку структур данных,
семантику операций, вычисление функций и организацию локальных и
рекурсивных окружений на языке Java.
